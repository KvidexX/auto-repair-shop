# Скриншоты

Актуальные шесть экранов приложения: `current_orders.png`, `current_clients.png`, `current_car.png`, `current_calendar.png`, `current_services.png`, `current_history.png`.

`stage92_edit_order.png`, `stage92_compact_clients.png`, `stage92_compact_services.png`, `stage92_calendar.png` показывают форму редактирования, компактные списки и календарь; они также пригодны для отчёта.

Прежние изображения сохранены по исходным путям для ранее подготовленных учебных материалов: `orders.png`, `new_order.png`, `order_card.png`, `completed_order.png`, `clients.png`, `add_client.png`, `cars.png`, `add_car.png`, `services.png`, `add_service.png`, `appointments.png`, `new_appointment.png`, `history.png`, `stage9_main.png`, `stage9_clients_popup.png`, `stage9_services_popup.png`, `stage9_calendar.png`. Они могут показывать оформление предыдущих версий и не используются как актуальная иллюстрация README.

Все записи вымышленные. PNG сохраняют физическое разрешение HiDPI и могут быть крупнее логического окна 1280×720.

Автоматические тесты пишут свои снимки в `.tmp/test-screenshots/` и не меняют эту папку. Обновлять документационные снимки следует отдельно, намеренно, через демонстрационный режим или `--screenshot`.
