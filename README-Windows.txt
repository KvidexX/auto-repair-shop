АвтоСервис — Windows x64

Распакуйте AutoService-Windows-x64.zip целиком. В папке AutoService
запустите AutoService.exe. Python и отдельные библиотеки не требуются.
Папку _internal необходимо хранить рядом с EXE и переносить вместе с ним.

При первом запуске разделы пусты. Данные сохраняются автоматически:
%LOCALAPPDATA%\AutoService\autoservice.db
Расположение программы и текущая папка не влияют на путь базы.

Доступны заказ-наряды, клиенты, автомобили, запись на обслуживание,
каталог услуг и история. Активный заказ можно редактировать до завершения.
Цены оставшихся работ не меняются при изменении каталога.
Завершённые заказы доступны только для просмотра.

Демонстрация без обращения к рабочей базе:
AutoService.exe --demo
Изменения в этом режиме исчезают после закрытия.

Перед обновлением схемы существующей базы программа создаёт отдельную
проверенную копию SQLite в папке AutoService\backups рядом с базой.
Если копия не создана, обновление не начинается. Старые копии сохраняются.
Не удаляйте базу при ошибке запуска. Закройте приложение перед ручным
копированием или восстановлением данных. Перенос папки программы
не переносит пользовательскую базу: её сохраняйте отдельно.
